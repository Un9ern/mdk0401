## 2. Обоснование выбора технологического стека

- **Python**: Язык с простым синтаксисом и огромным количеством библиотек для веб-разработки, работы с данными и автоматизации. Отличный выбор для быстрой и качественной разработки.
- **FastAPI**: Современный, быстрый веб-фреймворк для создания API. Автоматически генерирует документацию (Swagger UI) и обеспечивает высокую производительность. REST API на его основе станет надёжным «мостом» между фронтендом и бэкендом.
- **PostgreSQL**: Мощная и надёжная объектно-реляционная СУБД с открытым исходным кодом. Идеально подходит для хранения структурированных данных (книги, читатели, выдача) и обеспечивает целостность данных.
- **SQLAlchemy**: ORM (Object-Relational Mapping). Позволяет работать с PostgreSQL не через сырые SQL-запросы, а через Python-объекты. Делает код более чистым, безопасным и переносимым.
- **Pandas и Matplotlib**: Pandas — незаменимый инструмент для анализа и обработки данных (отчёты по выдаче). Matplotlib позволит строить наглядные графики и диаграммы.
- **VS Code**: Бесплатный, лёгкий и очень мощный редактор кода с огромным количеством расширений для Python.

## 3. Цель разработки и архитектура системы

**Цель**: Создать веб-приложение (и, возможно, десктопное) для автоматизации учёта книг, которое заменит ручной труд, ускорит поиск информации и сделает управление библиотекой прозрачным и эффективным.
