# 📚 Анализ и проектирование системы учёта книг в библиотеке

Данный репозиторий содержит результаты этапа анализа и проектирования перед разработкой веб- и десктопного приложения для автоматизации библиотечного учёта.

## 🎯 Цель проекта
Автоматизация учёта книг, замена ручного труда, ускорение поиска информации и создание прозрачной системы управления библиотекой.

## 📋 Содержание
Подробный анализ, сравнение с аналогами и обоснование выбора технологического стека доступны в файле **[ANALYSIS.md](./ANALYSIS.md)**.

## 🛠️ Краткий обзор стека
- **Backend:** Python, FastAPI, PostgreSQL, SQLAlchemy
- **Frontend:** Streamlit (Web), Tkinter (Desktop)
- **Аналитика:** Pandas, Matplotlib
- **Инструменты:** VS Code, REST API
